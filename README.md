## 项目简介

**MiroTab（灵境起始页）** 是一款使用纯原生 HTML / CSS / ES Modules 从零编写的浏览器新标签页扩展，无任何第三方运行时依赖、无需打包编译，也不依赖任何自建后端服务。

项目针对常见起始页在**代理环境下图标加载缓慢**、**内网 NAS / 自定义端口抓不到图标**以及**默认占位图标简陋**等痛点进行了专门设计，并在此基础上融合了**命令式聚合搜索、桌面级自由定位网格、6 款深度打磨的零阻塞小组件**以及致敬胡安·米罗（Joan Miró）的现代镜面美学。

## 核心特性

### 1. 零延迟本地持久化缓存（无视代理 / 断网秒开）
- **毫秒级预热瞬开**：所有抓取或上传的站点高清图标与壁纸均转为 `DataURL` 持久化存储在本地 `IndexedDB`（内置超时防阻塞保护），启动时毫秒级预热至内存 `Map`，每次新建标签页 **0 网络请求、0 白块闪烁**，挂代理或离线环境下依然瞬间全显。
- **自动垃圾回收与多端同步**：删除站点或小组件后自动清理无引用图标缓存、孤儿组件数据与过期必应壁纸；支持多标签页之间实时同步桌面与设置变更。

### 2. 四级智能图标引擎 & 图标工作室
- **L1 后台直连网页深度解析**：Manifest V3 Service Worker 直接复用浏览器网络栈（天然兼容系统代理分流与局域网 NAS / `localhost`），解析 HTML 中的高清 SVG、`apple-touch-icon`、PWA `manifest.json`、`msapplication-TileImage` 及根目录常见图标，并通过文件头二进制魔数校验过滤伪装成图片的错误页。
- **L2 浏览器原生缓存兜底**：调用 Chromium 扩展 `_favicon` 接口，即使站点开启 Cloudflare 防护或需要内网登录，只要浏览器访问过即可提取真实图标。
- **L3 隐私优先的公网串行兜底**：仅当直连全部失败且目标为**标准端口公网域名**时，才按顺序串行（绝不并发广播）尝试 DuckDuckGo / Google S2 / Yandex 图标源；严格拦截内网 IP、保留网段、私有域名后缀与非标端口。
- **L4 图标工作室与细节打磨**：
  - 支持一键深度探测网页全部候选图标自由挑选、上传本地图片（自动缩放压缩）、远程图片直链转本地缓存，以及方形封面铺满圆角（`fullBleed`）。
  - 内置 16 款渐变与纯色色板，支持自定义文字或 Emoji 徽章，未指定时根据中英文站名智能生成首字缩写。
  - **深色镂空图标智能衬底**：Canvas 自动识别纯黑/极暗透明图标（如 GitHub 等），在深色背景下自动补充柔和浅色衬底。

### 3. 命令式聚合搜索栏
- **12 款内置引擎 + 自定义引擎管理**：内置必应、Google、百度、Yandex、DuckDuckGo、GitHub、哔哩哔哩、知乎、小红书、YouTube、Perplexity、必应翻译；支持**添加任意自定义搜索引擎**（支持 `%s` 占位符、自定义底色与快捷前缀）及隐藏不常用内置引擎。
- **`!Bang` 快捷指令路由**：输入如 `!g 关键词`、`!gh 关键词`、`!b 关键词` 即可单次调用对应引擎搜索；仅输入 `!前缀` 回车可直接切换默认引擎，输入 `!` 自动弹出指令候选提示。
- **纯本地安全表达式计算器**：直接输入算式（如 `128 * 24`）或以 `=` 开头调用函数与常量（支持 `+ - * / % ^ × ÷` 及 `sqrt`、`abs`、`round`、`floor`、`ceil`、`pow`、`max`、`min`、`pi`、`e`），实时预览计算结果，回车或点击一键复制且绝不外发请求。
- **拼音首字母站内直达 & 双通道联想**：支持通过中文标题**拼音首字母**（基于零依赖 `Intl.Collator`）、标题或域名快速匹配并直达已添加站点；搜索联想采用「扩展前端直连 + Service Worker 兜底 + 5 分钟 TTL 缓存」，零冷启动延迟且高亮匹配词。

### 4. 桌面级自由网格、丝滑分组与书签目录导入
- **自由坐标摆位与文件夹**：支持图标与小组件拖拽至任意网格留白放置、同尺寸互换、碰撞自动避让，右键空白处可**一键自动整理对齐**；将图标拖入另一图标正中自动合并为桌面文件夹（文件夹内支持拖拽排序、直接添加网址、移出桌面与解散）。
- **阻尼滚轮切组与实时预览**：支持鼠标滚轮阻尼切换分组（含触控板惯性尾波抑制），向下滚动时底部实时浮现**下一分组首行预览（Next Group Peek）**；侧边栏支持拖拽分组排序、靠左边缘自动呼出跨组投递，以及右键分组**一键后台打开组内全部网址**。
- **完整书签目录树导入**：读取浏览器完整书签树，支持关键词筛选、目录折叠与整组勾选、海量书签分页加载、**自动跳过已存在网址去重**，并提供**平铺导入当前分组 / 子目录转为桌面文件夹 / 按目录新建独立分组**三种导入模式。

### 5. 6 款深度打磨的零阻塞小组件
所有小组件均支持自由拖拽排布与右键切换多尺寸规格：
- **日历**（`2x2` / `2x1`）：支持前后切月浏览与一键回到本月，内置零依赖 1900–2100 本地农历算法、**二十四节气**与**公历/传统农历节日**（含除夕）高亮标注。
- **待办事项**（`2x2` / `2x3`）：支持勾选完成、**双击原位编辑**、单项上移排序与一键清理已完成项，输入编辑时自动锁定卡片拖拽防误触。
- **灵感便签**（`2x2` / `2x3` / `3x2`）：支持**多页签管理**（最多 6 个页签，支持新建、删除与双击重命名）与**安全 Markdown 预览模式**（支持多级标题、粗斜体、删除线、行内代码、引用、超链接，以及 `- [ ]` 待办复选框直接点击联动更新原文）。
- **实时天气**（`2x2` / `2x1`）：接入 Open-Meteo 免费天气与地理编码接口（无需 API Key），支持中文/拼音搜索城市、实时温度/湿度/风速、**未来 3 日天气与温差预报**及手动刷新。
- **倒数日**（`2x1` / `2x2`）：支持**多事件管理与卡片内一键轮换**，支持**单次 / 每月 / 每年重复周期**自动推算（月末日期智能对齐），内置发薪日、元旦、周年纪念快捷模板。
- **模拟指针时钟**（`2x2`）：融合星芒刻度与红金撞色秒针，组件卸载自动清理定时器。

### 6. Miro 融合美学与模块化安全备份
- **四大主题与自适应感知**：内置 **自动 / 浅色 / 深色 / Miró 画廊** 四套主题（Miró 画廊采用暖米白画布纸感配墨线边框与红蓝黄原色点缀，切换时智能联动专属壁纸）；配备指针跟随镜面折光高光与**壁纸亮度自动采样感知**，点击顶部时钟可一键进入**极简专注模式**。
- **6 款时钟风格 & 多元壁纸**：提供**极简、米罗、海报、衬线、翻页、霓虹** 6 种时钟样式（可调字号、字重、12/24 小时制、秒数与农历显示）；内置 **12 款零延迟本地壁纸**、**微软必应每日壁纸**（支持近 8 天切换并本地缓存）及**自定义上传本地图片**（自动缩放至 `2560px` 内并采用 WebP/JPEG 压缩），支持模糊度与暗度无级调节。
- **脱敏导出与分模块选择性恢复**：支持一键**导出脱敏配置**与完整 JSON 备份；导入备份时自动统计内容并支持**按模块勾选恢复**（分组与桌面图标 / 外观与个性化设置 / 小组件数据 / 搜索历史记录），避免强制全量覆盖。

## 快捷键与高效交互速查

| 快捷键 / 操作 | 功能说明 |
| :--- | :--- |
| `/` 或 `Ctrl / Cmd + K` | 任意位置一键聚焦并选中搜索框文本 |

## 安装指南

本项目为纯静态原生代码，无需安装 `Node.js` 或执行任何构建打包命令，下载源码后即可在任意 Chromium 内核浏览器（Edge / Chrome / Brave / Arc / Vivaldi 等）中直接加载：

1. 下载本仓库代码（`git clone` 或点击页面右上角 **Code → Download ZIP** 并解压到本地固定目录）。
2. 在浏览器地址栏打开扩展管理页面：
   - **Microsoft Edge**：`edge://extensions/`
   - **Google Chrome**：`chrome://extensions/`
3. 开启页面角落的 **「开发人员模式」**（Developer mode）开关。
4. 点击 **「加载解压缩的扩展」**（Load unpacked），选择解压后的本项目根目录（包含 `manifest.json` 的文件夹）。
5. 按 `Ctrl + T`（macOS 为 `Cmd + T`）新建标签页即可立即体验。（若浏览器已启用其他新标签页扩展，建议先将其关闭以避免接管冲突。）

> **提示**：你也可以通过本地静态服务器直接打开 `newtab.html` 进行网页端预览；在非扩展预览模式下，受浏览器同源策略限制的功能（如跨站 HTML 图标深抓、浏览器书签树读取、必应壁纸直连）会自动平滑降级且不发送未授权请求。

## 权限与隐私安全说明

MiroTab 完全在用户浏览器本地运行，**无任何遥测埋点，不收集、不追踪、不向任何自建服务器上传任何用户数据**。

- **扩展权限用途**：
  - `storage`：用于基础扩展状态管理（核心桌面配置与图标缓存存储于本地 `localStorage` 与 `IndexedDB`，并自动清理已删除组件与无引用图标缓存）。
  - `favicon`：读取浏览器本地已缓存的站点图标，作为防爬或登录态站点的纯本地兜底方案。
  - `bookmarks`：仅在用户主动打开「导入书签」面板时读取本地书签目录树。
  - `host_permissions: <all_urls>`：用于在本地抓取用户所添加网站的 HTML / Manifest / Favicon 图标、微软必应每日壁纸及当前所选搜索引擎的联想词。
- **内置隐私与安全防线**：
  - **搜索联想严格隔离**：联想请求**仅发往当前激活的单一搜索引擎**（绝不跨厂商并发回退），并自动跳过网址、内网地址、数学算式、`!Bang` 指令、邮箱及长 Token 等敏感输入；危险协议（`javascript:` / `data:` / `file:` 等）均在前端直接拦截；关闭「显示搜索历史记录」开关时立即清空本地历史。
  - **内网与私有地址零泄露**：严格拦截 `localhost`、单标签主机名、`.local` / `.lan` / `.internal` / `.home.arpa` / `.ts.net` 等私有后缀、全部私有/保留 IPv4（含 Tailscale CGNAT `100.64.0.0/10`）、IPv6 字面量及非标端口向第三方公网图标源发包；公网图标兜底亦采用串行按需请求而非多家广播，且本地 `IndexedDB` 缓存不保存完整原始 URL。
  - **严格 CSP 与安全渲染**：启用无内联脚本 CSP（`script-src 'self'; object-src 'none'`），所有动态文本与便签 Markdown 渲染均经过 HTML 转义与协议白名单校验。
  - **脱敏导出与彻底重置**：支持一键「导出脱敏配置」（自动剥离搜索历史、便签/待办/倒数日/天气数据、自定义壁纸、内网网址、自定义内网搜索引擎及 URL 中的账号密码凭据）；恢复出厂设置时同步彻底清空 `localStorage`（含历史旧版遗留键）与 `IndexedDB` 全部缓存。
