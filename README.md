## 项目简介

**MiroTab（灵境起始页）** 是一款使用纯原生 HTML / CSS / ES Modules 从零编写的浏览器新标签页扩展，无任何第三方运行时依赖、无需打包编译，也不依赖任何自建后端服务。

项目针对常见起始页在**代理环境下图标加载缓慢**、**内网 NAS / 自定义端口抓不到图标**以及**默认占位图标简陋**等痛点进行了专门设计，并在此基础上融合了**命令式聚合搜索、桌面级自由定位网格、6 款深度打磨的零阻塞小组件**以及致敬胡安·米罗（Joan Miró）的现代镜面美学。

## 核心特性

### 1. 零延迟本地持久化缓存（无视代理 / 断网秒开）
- **本地缓存与离线优先**：所有已缓存的站点高清图标与壁纸均转为 `DataURL` 持久化存储在本地 `IndexedDB`（内置超时防阻塞保护），启动时毫秒级预热至内存 `Map`。当桌面图标均已缓存（或显示本地文字徽章）且未启用联网天气/在线壁纸/联网搜索预测时，新建标签页可做到 **0 网络请求、0 白块闪烁**。
- **自动垃圾回收与多端同步**：删除站点或小组件后自动清理无引用图标缓存、孤儿组件数据与过期必应壁纸；支持多标签页之间实时同步桌面与设置变更。

### 2. 多级本地优先图标引擎 & 图标工作室
- **本地优先默认显示**：新建标签页默认依次检查**扩展本地缓存（内存 / `IndexedDB`）→ 浏览器原生 `_favicon` 本地缓存 → 本地智能渐变文字徽章**，默认不向站点后台发包。
- **按需深度抓取与跨源校验**：点击「深度抓取网页图标」「重新抓取网页图标」或「批量重抓全部图标」并授予对应站点权限后，Service Worker 默认仅从**站点根地址（协议 + 域名 + 端口，不发送私有路径或查询参数）**解析 HTML 中的高清 SVG、`apple-touch-icon`、PWA `manifest.json`、`msapplication-TileImage` 及根目录常见图标，并对跨源引用与 HTTP 重定向目标执行隔离校验，防止公网页面跳转至内网主机。
- **可选单一第三方兜底**：默认关闭第三方图标服务；用户可在设置中主动开启并指定**单一**服务（DuckDuckGo / Google S2 / Yandex），仅在直连失败且目标为标准端口公网域名时才会请求所选服务。
- **图标工作室与细节打磨**：
  - 支持深度探测网页候选图标挑选、上传本地图片（自动缩放压缩）、远程图片直链转本地缓存（失败或未授权时回退为本地徽章，不在页面直接外链加载），以及方形封面铺满圆角（`fullBleed`）。
  - 内置 16 款渐变与纯色色板，支持自定义文字或 Emoji 徽章，未指定时根据中英文站名智能生成首字缩写。
  - **深色镂空图标智能衬底**：Canvas 自动识别纯黑/极暗透明图标（如 GitHub 等），在深色背景下自动补充柔和浅色衬底。

### 3. 命令式聚合搜索栏
- **12 款内置引擎 + 自定义引擎管理**：内置必应、Google、百度、Yandex、DuckDuckGo、GitHub、哔哩哔哩、知乎、小红书、YouTube、Perplexity、必应翻译；支持**添加任意自定义搜索引擎**（支持 `%s` 占位符、自定义底色与快捷前缀）及隐藏不常用内置引擎。
- **`!Bang` 快捷指令路由**：输入如 `!g 关键词`、`!gh 关键词`、`!b 关键词` 即可单次调用对应引擎搜索；仅输入 `!前缀` 回车可直接切换默认引擎，输入 `!` 自动弹出指令候选提示。
- **纯本地安全表达式计算器**：直接输入算式（如 `128 * 24`）或以 `=` 开头调用函数与常量（支持 `+ - * / % ^ × ÷` 及 `sqrt`、`abs`、`round`、`floor`、`ceil`、`pow`、`max`、`min`、`pi`、`e`），实时预览计算结果，回车或点击一键复制且绝不外发请求。
- **拼音首字母站内直达 & 按需联网联想**：支持通过中文标题**拼音首字母**（基于零依赖 `Intl.Collator`）、标题或域名纯本地直达已添加站点；**联网搜索预测默认关闭**，需在设置中主动开启并授权后，才会在输入时向当前激活引擎发送联想请求，关闭开关立即取消在途请求并清空缓存。

### 4. 桌面级自由网格、丝滑分组与书签目录导入
- **自由坐标摆位与文件夹**：支持图标与小组件拖拽至任意网格留白放置、同尺寸互换、碰撞自动避让，右键空白处可**一键自动整理对齐**；将图标拖入另一图标正中自动合并为桌面文件夹（文件夹内支持拖拽排序、直接添加网址、移出桌面与解散）。
- **阻尼滚轮切组与实时预览**：支持鼠标滚轮阻尼切换分组（含触控板惯性尾波抑制），向下滚动时底部实时浮现**下一分组首行预览（Next Group Peek）**；侧边栏支持拖拽分组排序、靠左边缘自动呼出跨组投递，以及右键分组**一键后台打开组内全部网址**。
- **完整书签目录树导入**：读取浏览器完整书签树，支持关键词筛选、目录折叠与整组勾选、海量书签分页加载、**自动跳过已存在网址去重**，并提供**平铺导入当前分组 / 子目录转为桌面文件夹 / 按目录新建独立分组**三种导入模式。

### 5. 6 款深度打磨的零阻塞小组件
所有小组件均支持自由拖拽排布与右键切换多尺寸规格：
- **日历**（`2x2` / `2x1`）：支持前后切月浏览与一键回到本月，内置零依赖 1900–2100 本地农历算法、**二十四节气**与**公历/传统农历节日**（含除夕）高亮标注。
- **待办事项**（`2x2` / `2x3`）：支持勾选完成、**双击原位编辑**、单项上移排序与一键清理已完成项，输入编辑时自动锁定卡片拖拽防误触。
- **灵感便签**（`2x2` / `2x3` / `3x2`）：支持**多页签管理**（最多 6 个页签，支持新建、删除与双击重命名）与**安全 Markdown 预览模式**（支持多级标题、粗斜体、删除线、行内代码、引用、超链接，以及 `- [ ]` 待办复选框直接点击联动更新原文）。
- **实时天气**（`2x2` / `2x1`）：接入 Open-Meteo 免费天气与地理编码接口（无需 API Key），支持中文/拼音搜索城市、实时温度/湿度/风速、**未来 3 日天气与温差预报**及手动刷新。
- **倒数日**（`2x1` / `2x2`）：支持**多事件管理与卡片内一键轮换**，支持**单次 / 每月 / 每年重复周期**自动推算（月末日期智能对齐），内置发薪日、元旦、周年纪念快捷模板。
- **模拟指针时钟**（`2x2`）：融合星芒刻度与红金撞色秒针，组件卸载自动清理定时器。

### 6. Miro 融合美学与模块化安全备份
- **四大主题与自适应感知**：内置 **自动 / 浅色 / 深色 / Miró 画廊** 四套主题（Miró 画廊采用暖米白画布纸感配墨线边框与红蓝黄原色点缀，切换时智能联动专属壁纸）；配备指针跟随镜面折光高光与**壁纸亮度自动采样感知**，点击顶部时钟可一键进入**极简专注模式**。
- **6 款时钟风格 & 多元壁纸**：提供**极简、米罗、海报、衬线、翻页、霓虹** 6 种时钟样式（可调字号、字重、12/24 小时制、秒数与农历显示）；内置 **12 款零延迟本地壁纸**、**微软必应每日壁纸**（支持近 8 天切换并本地缓存）及**自定义上传本地图片**（自动缩放至 `2560px` 内并采用 WebP/JPEG 压缩），支持模糊度与暗度无级调节。
- **白名单脱敏导出与分模块校验恢复**：导出脱敏配置采用严格白名单，默认仅保留公网站点的协议、域名与端口，并在预览弹窗确认后下载；导入备份支持**按模块勾选恢复**（分组与桌面图标 / 外观与个性化设置 / 小组件数据 / 搜索历史记录），导入前校验字段类型、数值范围与文件大小，并在更改默认搜索引擎时提前展示目标域名。

## 安装指南

本项目为纯静态原生代码，无需安装 `Node.js` 或执行任何构建打包命令，下载源码后即可在任意 Chromium 内核浏览器（Edge / Chrome / Brave / Arc / Vivaldi 等）中直接加载：

1. 下载本仓库代码（`git clone` 或点击页面右上角 **Code → Download ZIP** 并解压到本地固定目录）。
2. 在浏览器地址栏打开扩展管理页面：
   - **Microsoft Edge**：`edge://extensions/`
   - **Google Chrome**：`chrome://extensions/`
3. 开启页面角落的 **「开发人员模式」**（Developer mode）开关。
4. 点击 **「加载解压缩的扩展」**（Load unpacked），选择解压后的本项目根目录（包含 `manifest.json` 的文件夹）。
5. 按 `Ctrl + T`（macOS 为 `Cmd + T`）新建标签页即可立即体验。（若浏览器已启用其他新标签页扩展，建议先将其关闭以避免接管冲突。）

> **提示**：你也可以通过本地静态服务器直接打开 `newtab.html` 进行网页端预览；在非扩展预览模式下，受浏览器同源策略限制的功能（如跨站 HTML 图标深抓、浏览器书签树读取、必应壁纸直连）会自动平滑降级且不发送未授权请求。

## 权限与隐私安全说明

MiroTab 完全在用户浏览器本地运行，**无任何遥测埋点，不收集、不追踪、不向任何自建服务器上传任何用户数据**。所有桌面配置与缓存均存储于浏览器本地 `localStorage` 与 `IndexedDB`。

- **扩展按需权限用途**：
  - `favicon`（安装即声明）：读取浏览器本地已缓存的站点图标，作为离线优先的纯本地图标源。
  - `optional_permissions: bookmarks`（按需申请）：仅在用户打开「导入书签」面板并点击授权时申请读取本地书签目录树；拒绝授权不影响新标签页其余功能。
  - `optional_host_permissions: <all_urls>`（按需申请）：仅在用户主动触发抓图、开启联网搜索预测或选用必应每日壁纸时，按具体操作域名申请所需主机权限；默认新标签页不持有一揽子全网访问权限。
- **联网功能触发条件说明**：

| 功能 | 实际网络行为与触发条件 | 控制与关闭方式 |
| :--- | :--- | :--- |
| **图标加载** | 默认仅读本地 `IndexedDB` 与浏览器 `_favicon` 缓存，未命中时显示本地文字徽章；仅在用户主动点击抓图/重抓并授权后，才从目标站点根地址请求图标；若在设置中主动开启第三方兜底，直连失败后仅向**选定的单一服务**（DuckDuckGo / Google S2 / Yandex）发送符合规则的公网域名。 | 默认离线徽章；设置中可关闭第三方图标兜底 |
| **搜索预测** | **默认关闭**（纯本地匹配已添加站点的标题、域名与拼音首字母）。主动开启并授权后，输入停顿约 100ms 会向当前激活引擎（如必应/百度/Google 等支持的提供方）发送输入片段；输入 URL、内网地址、邮箱、算式、`!Bang` 或 32 位以上连续字符会自动跳过，但无法保护此前已发出的前缀。 | 设置 →「输入时向当前搜索引擎请求联想词」 |
| **天气组件** | 仅在桌面添加了天气小组件时，当缓存超过 30 分钟或手动点击刷新，向 `api.open-meteo.com` 发送当前所选城市的经纬度坐标；更换城市搜索时，`geocoding-api.open-meteo.com` 会接收输入的城市名。**扩展不读取浏览器或设备地理位置权限。** | 不添加天气组件或移除组件即可停止请求 |
| **桌面壁纸** | 默认本地渐变/SVG 壁纸与用户上传的本地图片完全离线生成。仅当选用「必应每日壁纸」并授权访问微软服务、且当日本地 `IndexedDB` 缓存未命中时，向 `cn.bing.com` / `www.bing.com` 请求每日壁纸。 | 设置 → 壁纸背景切换为内置渐变或本地上传 |

- **内置隐私与安全防线**：
  - **内网与私有地址拦截规则（含局限性说明）**：针对第三方图标兜底与跨源重定向，代码通过主机名与字面量规则拦截 `localhost`、单标签主机名、`.local` / `.lan` / `.internal` / `.home.arpa` / `.ts.net` 等私有后缀、私有/保留 IPv4（含 CGNAT `100.64.0.0/10`）、IPv6 字面量及非标端口。**需注意**：基于域名规则的静态判断无法识别通过自定义公网域名解析至内网 IP（如内网 DNS Split-Horizon）或非标准私有后缀的地址；同时，用户主动在桌面添加的内网 NAS 服务本身在点击「深度抓取」并授权后仍可直接从其同源根地址取图。
  - **严格 CSP 与安全导入渲染**：启用无内联脚本 CSP（`script-src 'self'; object-src 'none'; img-src 'self' data: blob: https: chrome-extension:;`）；导入备份前校验文件大小、字段类型与数值范围，设置页通过 DOM 属性与 `textContent` 安全赋值。
  - **白名单脱敏导出与彻底重置**：脱敏分享导出采用严格白名单（默认仅留公网站点协议、域名与端口，可在预览确认后自选是否保留标题、自定义图标或非内网自定义引擎）；恢复出厂设置时使在途抓图/壁纸任务失效，并等待 `IndexedDB` 清理事务提交完成后准确反馈清理结果。
